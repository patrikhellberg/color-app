# Color app

A simple application that allows for setting the color of your screen.

[Visit the app](https://color.hellberg.io)

## Development

A Vite + React app. Requires Node 24 and pnpm.

```sh
pnpm install
pnpm dev      # start the dev server
pnpm lint     # oxlint
pnpm build    # typecheck and build to dist/
pnpm preview  # serve the built app
```
